## Groupy 到底能合并什么，和系统自带标签差在哪

用法就是拖。打开几个窗口，把一个窗口拖到另一个窗口的标题区域，两者就合成一个带标签的窗口，之后拖进来的窗口会自动变成新标签。合并的对象几乎是任何 Windows 程序，不限于浏览器或者资源管理器。

标签能放在窗口顶部还是底部、要不要显示图标、用传统样式还是 Win11 那种圆角样式，都可以改，另外还支持 Win11 的 Mica 视觉效果。常用的组合可以存成一组，下次一键拉起来，整组还能固定到任务栏，任务栏上只占一个位置。

和 Windows 11 自带标签的区别在这儿：系统自带的标签只服务文件资源管理器，你在 Word 和 PDF 之间来回切，它管不了。Groupy 是跨程序的，写方案的时候把 Word 和参考文献的 PDF 放一组，中间再拖进一个素材文件夹，这才是它真正省时间的地方。浏览器自己的标签它也不替代，Chrome 里那几十个标签还是浏览器管自己的。

代价是它得常驻后台运行，属于“装了才有用”的那种工具。现在电脑上多一个常驻进程，对性能影响不大，但如果你不喜欢托盘里多一个图标，这一点得先想清楚。
